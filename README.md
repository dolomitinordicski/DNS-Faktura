# DNS Faktura

Internal billing-preparation tool for Dolomiti NordicSki.

DNS Faktura calculates and reviews billable amounts by canonical organization and reporting area. It consumes DNS source data (FAIR contribution, IDM Premiumpartner, Orders and controlled seasonal extras) and produces an internal preparation summary.

It does **not** create official invoices, track payments or integrate accounting software.

Architecture source: [dolomitinordicski/dns-shared-data](https://github.com/dolomitinordicski/dns-shared-data)
